# Frontino IT — Website

Static website for Frontino IT Consulting GmbH: SAP consulting and product engineering. Pure HTML, CSS and vanilla JavaScript, with no framework and no build step.

## Structure

- `index.html` and the other `.html` files: one file per page (services, landing pages, Vendor Date Hub, About, Contact, Blog and articles, legal pages, `404.html`).
- `style.css`: all styles.
- `main.js`: navigation, scroll and entrance animations, FAQ accordions, forms and the mobile form effect.
- `assets/`: logos, team photos, share images and videos (hero background and Vendor Date Hub demos).
- `sitemap.xml` and `robots.txt`: for search engines. They use the domain `https://frontinoit.com/`.

## Publishing

Upload the repository root to any static host (GitHub Pages, Netlify, Vercel or a web server). The site root is this folder; `index.html` is the homepage.
