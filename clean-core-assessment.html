Clean Core

Identify what should stay in the SAP core, what should move to BTP, and what should be retired.

The Clean Core Extension Assessment is a structured review of your custom SAP code — classifying every Z-object and modification against SAP's clean-core standard and producing a prioritized migration roadmap.

Assess your extensions See how it works
The Problem

Custom code is the number one blocker for SAP Cloud adoption.

Years of modifications, Z-programs, and custom enhancements accumulate silently — until the moment you try to upgrade or move to SAP Cloud, and everything stops.

  • Thousands of Z-objects with no documentation and unknown business owners
  • SAP upgrades blocked or heavily tested because of core modifications
  • Cloud migration scope overestimated because nobody knows what custom code is actually used
  • Annual maintenance costs inflated by code that no longer serves a business purpose
  • No roadmap for how to move from where you are to a clean-core architecture
The Outcome

A complete picture of your custom code — and a clear path to clean core.

  • Full inventory of custom objects with usage frequency and business criticality
  • Classification of every object: Retire / Keep / Migrate to BTP
  • BTP extension candidates with recommended approach for each
  • Realistic effort estimates and phased migration roadmap
  • Reduced cloud migration scope and cost baseline for vendor negotiations
Our Framework

Three verdicts. Every object gets one.

We classify your custom code using SAP's clean-core extensibility model combined with real usage data from your system — not just a theoretical framework.

Classification What it means Typical examples Next action
Retire Object has no active users, no business function, or duplicates standard SAP functionality Unused Z-reports, deprecated workarounds, replaced form outputs Decommission — reduce maintenance scope immediately
Keep Object uses standard SAP extensibility (BAdI, CDS View, RAP) — already clean-core compliant Enhancement implementations, standard BAdi exits, key-user extensibility Document and govern — no migration needed
Migrate to BTP Object modifies core tables or uses non-standard ABAP techniques — must move to BTP side-by-side Core-modifying user exits, Z-tables with business logic, custom reports on standard tables Design BTP extension and plan phased migration
The Process

How the assessment works.

Five structured phases. Minimal disruption to your team. Maximum clarity on your custom code landscape.

01

Object Extraction

We extract the full inventory of custom objects from your system using standard SAP tools — Z-programs, BAdi implementations, enhancements, modifications, and Z-tables.

Day 1–2
02

Usage Analysis

We analyze transaction usage logs to identify active vs. dormant objects — filtering out the code that nobody uses before spending time classifying it.

Days 2–3
03

Technical Classification

Senior ABAP architects review active objects against SAP's clean-core extensibility model and assign a classification: Retire, Keep, or Migrate to BTP.

Days 4–7
04

Business Validation

We run a short validation session with your key process owners to confirm business criticality and identify any objects flagged incorrectly by technical analysis alone.

Days 8–9
05

Roadmap & Report

We deliver the full classification report, phased migration roadmap, BTP extension candidates list, and a 90-minute readout with your team.

Day 10
What You Receive

A complete clean-core action plan.

  • Custom Code Inventory — full list of all Z-objects with usage frequency, technical type, and business process mapping
  • Classification Report — every object classified as Retire / Keep / Migrate with documented rationale
  • BTP Extension Candidates — prioritized list of Migrate objects with recommended BTP pattern (side-by-side app, iFlow, SAP Build workflow)
  • Phased Migration Roadmap — 3-horizon plan (quick wins / mid-term / long-term) with effort estimates per object group
  • Quick Win List — objects that can be retired immediately with zero risk, for fast scope reduction
  • Readout Session — 90-minute walkthrough with your IT leadership and key process owners to discuss findings and priorities

Use the results regardless of what comes next.

The assessment report is yours to use — for internal planning, SAP partner negotiations, board approval, or as a baseline for your cloud migration RFP. No lock-in.

Clients typically retire 40–60% of custom code immediately after receiving the quick win list.
